# Spotify Mood Evaluator API

Backend API for Playlist Mood Evaluator frontend application.

## Local Development

### Start API

To spin up the API locally, using the following command:

```
fastapi dev main.py
```

This will launch a Uvicorn server on `http://127.0.0.1:8000`.

### Deployment

To deploy changes to remote Fly.io server, run:

```
fly deploy
```
